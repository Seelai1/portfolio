Project 04

Network Monitoring

Waarover gaat dit project?

Met netwerkmonitoring kun je opvolgen wat er op een netwerk gebeurt. In dit project ligt de focus op het zichtbaar maken van informatie, zodat je sneller merkt wanneer er iets niet loopt zoals verwacht.

Wat komt erbij kijken?

  • Bekijken welke netwerkgegevens nuttig zijn om op te volgen.
  • Een dashboard gebruiken om informatie duidelijk weer te geven.
  • Nagaan hoe monitoring kan helpen om problemen sneller op te sporen.

Wat heb ik geleerd?

Ik zie beter waarom monitoring belangrijk is voor netwerkbeheer. Als informatie duidelijk wordt weergegeven, kun je veranderingen sneller opmerken en gerichter op zoek gaan naar de oorzaak van een probleem.
