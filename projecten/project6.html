Project 06

Network Automation

Waarover gaat dit project?

Bij netwerkautomatisering onderzoek ik hoe kleine scripts terugkerende taken eenvoudiger kunnen maken. Zo hoef je bepaalde handelingen niet telkens opnieuw manueel uit te voeren.

Wat komt erbij kijken?

  • Herkennen welke netwerkbeheertaken vaak terugkomen.
  • Bekijken hoe een script zulke stappen kan automatiseren.
  • Aandacht besteden aan testen en controleren voordat je een script gebruikt.

Wat heb ik geleerd?

Ik heb geleerd dat automatisering vooral nuttig is bij taken die vaak terugkomen. Tegelijk blijft controleren belangrijk: een script moet betrouwbaar werken en mag niet zomaar op elke situatie toegepast worden.
